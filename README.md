# Truong Lieu Dong (Vigo) Dang Portfolio

Static portfolio prepared for GitHub Pages.

## Local Commands

```powershell
npm.cmd run build
npm.cmd run check
npm.cmd run serve
```

The resume download UI expects a final PDF at:

```text
src/assets/resume-truong-lieu-dong-vigo-dang.pdf
```

## GitHub Pages

Use the included workflow in `.github/workflows/pages.yml` after review.
It builds the static site into `dist/` and publishes that folder.
