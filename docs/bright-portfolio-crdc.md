## What the live CRDC demo demonstrates

[CRDC Research Assistant](https://crdc-research-assistant.jazzyactor4.chatgpt.site/) is an existing public static deployment on ChatGPT Sites. The portfolio links to that deployment; it does not redeploy the Python application.

The browser-only demo reuses the application interface with three hand-authored sample reports and two synthetic source notes. Visitors can choose a question, inspect cited passages and export HTML/Markdown. No account, model download or API key is required. It does not upload documents, run AI or perform automated review. The original Python retrieval/specialist/synthesis application and optional hosted configuration are separate from this public demo. Team attribution and private research boundaries remain in the case study and game.

`src/assets/crdc-research-demo.jpg` is an unaltered 1440×1050 browser capture of the public report view on 18 November 2026. All three reports, citation-to-source navigation, and HTML/Markdown downloads were exercised. No original corpus documents, private reports or repository history were copied.

## Validation and publishing

Run `npm.cmd install --ignore-scripts`, `npm.cmd run build`, then `npm.cmd run check`. The release guard requires 23 routes, both independent stylesheet orders, the approved light portfolio palette, both PDFs, the demo capture, source/build asset identity and Pages manifest provenance. Tests reject missing/mis-cased demo assets and regression to the previous dark portfolio palette.

The existing GitHub Actions workflow validates pull requests and publishes `dist/` only from main. Source review and actual Actions/deployed-resource results determine release status. Local caches, `dist/`, tooling and review captures are excluded from the release commit.
