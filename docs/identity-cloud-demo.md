# A clearer hiring story and Dataset demo — 19 November 2026

## Direction

Vigo selected Data and Cloud Engineering internships/graduate roles as the primary audience. The site introduces a person and a hiring intention before listing tools. About uses supplied facts: he grew up in Biên Hòa, Đồng Nai and is based in Brisbane; he describes himself as willing to listen, accept feedback and improve. The existing light palette, portrait and illustrated Asian night market remain. National imagery and invented personal memories are not added.

Work is ordered around data/cloud workflows, then applied AI and software foundations. Every original case, proof statement, measurement, source artifact and résumé remains. Two live interfaces share one compact homepage section. Visitors can read evidence and contact Vigo without playing.

## Dataset demo boundary

The existing public demo at https://vigodang.github.io/dataset-health-analyzer-demo/ performs real browser-local CSV analysis with a reused analytics engine. Three bundled datasets are synthetic. Report tabs cover Overview, Data Quality, Distributions, Statistics, Correlations, Outliers, Columns and Processing. JSON export and a small generated CSV were exercised in the actual public browser on 19 November 2026. There were no POST requests. Limits are 1 MiB, 5,000 rows and 30 columns; contents/results live in tab memory and reset on reload.

The page is a static React/Vite deployment on GitHub Pages. It does not run Cognito, S3, SQS, Fargate or the original AWS queue. Seeded lifecycle dates and queued/failed examples are illustrative. The archived 12 October AWS experiment (40/40 jobs; observed workers 1 → 4 → 1) remains dated, separate evidence. Its 80,001-row workload is not reproduced by the public demo.

`src/assets/dataset-health-demo.jpg` is an unaltered 1440×1050 capture of the actual deployed report using the synthetic retail example. The original report image, correlations, architecture, CSV and scaling figure remain accessible through cases, viewers and game evidence.

## Why play

The short suggested walk starts at Cloud Kitchen (make work/status understandable), continues to AI Alley (question a source), and ends with a conversation invitation. The Next action appears only after genuine Cloud completion and reuses existing district travel/mission controls. The other four missions remain optional exploration. There is no new tour counter, score, badge or requirement to finish six missions before viewing career links.

Each mission connects an existing implementation choice to a self-described working habit and a future improvement. The original educational limitations remain. The game is a fictional introduction to Vigo’s approach, not evidence that a player’s completion validates soft skills.

## Release checks

Use `npm.cmd install --ignore-scripts`, `npm.cmd run build`, then `npm.cmd run check`. The required route set stays 23 HTML pages and the protected non-HTML set becomes 56 assets. Both current and legacy PDFs, approved light tokens, independent CSS orders, manifest provenance and Pages publishing gates stay protected. Missing/mis-cased Dataset demo images now have release regression checks.

Only the portfolio repository is edited/published by this change. The two external demos keep their existing hosting and access. No private corpus, source credentials, original research findings, cloud resources or accounts are introduced.
